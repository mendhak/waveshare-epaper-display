You can use Google Calendar, Outlook Calendar, ICS, or CalDav to display events. You can mix and match providers, and add multiple calendars of each type. Events from all enabled calendars will be merged and sorted by date.

Set up each provider below:

* [Google Calendar](/calendar/google/)
* [Outlook Calendar](/calendar/outlook/)
* [ICS Calendar](/calendar/ics/)
* [CalDav Calendar](/calendar/caldav/)
