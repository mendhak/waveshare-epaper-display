Core display settings, all edited in `config.toml`:

* [Waveshare version](/configuration/waveshare-version/) — which revision of the 7.5" module you have.
* [Location](/configuration/location/) — latitude/longitude and units.
* [Layout](/configuration/layout/) — which of the screen layouts to use.

Weather, alerts, and calendar providers are configured in their own sections once your location is set.
