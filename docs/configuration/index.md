The main display settings, in `config.toml`:

* [Waveshare version](/configuration/waveshare-version/) - which version of the 7.5" module you have.
* [Location](/configuration/location/) - latitude/longitude and units, needed for weather.
* [Layout](/configuration/layout/) - which screen layout to use.

Weather, alerts, and calendar providers are configured in their own sections once your location is set.
